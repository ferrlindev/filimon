<objective>
Complete the `[host.oauth]` table that plan 06-01 started: add `client_secret_env`, `revocation_url`, `redirect_port` and `authorize_params`, enforce the full set of rules (https with no user-info on every endpoint, port range, scope text, parameter collisions), and resolve the client secret through the existing `.env` rules into a field the guest can never reach.

Purpose: D-11, D-12, D-13, D-14 and the default of D-04. Everything the login flow, the token client and logout read from a plugin's TOML comes from this table, so its validation and its secret handling must be complete before those plans run.

Output: the full OAuth config in `config.rs`, two new `ConfigError` variants, `resolve_oauth_secret` in `secrets.rs`, an updated test helper in `auth/testing.rs`, and the tests.

Flagged assumptions (edge probe; the user has not ruled): `client_secret_env` is the only secret key (no inline `client_secret`, by D-12); `authorize_params` values may be empty strings and are not otherwise validated, because the provider decides what it accepts; scopes with spaces are rejected rather than split, since one list entry is one scope.

Reversibility: the `[host.oauth]` shape (D-11, D-14) is rated costly in CONTEXT.md and settled. The default port 17420 is also costly in practice: a provider app registers the exact redirect URI `http://127.0.0.1:17420/callback`, so changing the default later breaks every app registered with it. It is flagged here, documented in plan 06-09's README section, and overridable per plugin by `redirect_port`; no decision checkpoint is added because it is a free choice (RESEARCH A1) with a per-plugin override.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| plugin TOML to host config | Endpoint URLs, ports, scopes and parameters come from a file a plugin author wrote |
| `.env` and process environment to host | The client secret enters here and must stop at the host |
| host config to third-party guest | `init` receives secrets; the client secret must not be among them |
