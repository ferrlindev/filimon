## Planner decisions recorded for this plan

- **D-06 check (done at plan time):** `grep -rn deny_unknown_fields smartmodules/` returns nothing. `RawPage` in `smartmodules/map-preprocess/src/lib.rs:19-23` and `smartmodules/map-extract/src/lib.rs:24-27` is `{ url: String, html: String }`, so the field names match `SourceItem` exactly. `html` is `String`, not `Option`. Serde accepts a missing unknown field but rejects `null` for `String`, so `SourceItem.html` must use `skip_serializing_if = "Option::is_none"` (RESEARCH Pitfall 1).
- **Live evidence (planner probe, 2026-11-04, local cluster):** the record already on `filimon-raw-pages` (the README `Tech Market Surges` sample) passes the full chain with `relevance_score` 0.4477. On a scratch topic, SourceItem-shaped news records with html `<p>lol cat</p>` and `<p>it is what it is</p>` scored 0.0 through preprocess and extract and were dropped by the full chain. Plan 02 uses `lol cat` as the SC3 contrast case.
- **Claude's discretion, chosen here:** the types live in `src/models.rs` (RESEARCH Pattern 1/5). JSON output is a pretty-printed array written by `save_json`, default `output/wise_output.json`, which is gitignored (A5). Streaming mode (`--limit 0`) stays print-only with no NER, which is the existing gap. News `platform` drops one leading `www.` (A1). File URLs and hostless or unparsable URLs get `local` (A2). Offset-less and date-only news dates are read as UTC (A3). Social `raw` is embedded as parsed JSON, falling back to a JSON string (A4).
- **`run_file` URL format is unchanged.** `format!("file://{}", path.display())` with a relative path yields `file://examples/...`, which the `url` crate parses with host `examples`. `platform_from_url` therefore checks for scheme `file` before reading the host.
- **Untouched on purpose (existing fluvio-wise gaps, STATE.md):** `TypedConsumer`, `FluvioStream::consumer`, `PipelineCoordinator`, `watch.rs`, the commented-out blocks in `main.rs` (lines 104-176, 178-230, 233-319), the unused `--threshold` flag, and `load_ner_engine`'s silent fallback. Once consume stops using `TypedConsumer`, rustc may add dead-code notices for it. The streaming.rs clippy gate below counts only warnings that are not dead-code notices.
- **Test gate:** `cargo test -p filimon`, never `--workspace`. `map-preprocess::tests::test_lemmatize` already fails at HEAD and must not be touched (D-01). Cluster tests are `#[ignore]` and use scratch topics only.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| crawled web page / local HTML file → `filimon-raw-pages` | Page content is untrusted. It becomes `html` and later title, author and text. |
| any Fluvio producer → `filimon-raw-pages` → `fili consume` | Any client with cluster access can write records that the chain and the consumer parse. |
| `fili consume` → operator terminal | Record text is printed by `print_summary`. |
| `fili consume` → local filesystem | The JSON output is written to a fixed relative path (operator-supplied in Plan 02). |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|

Both consumers use `RetryMode::Disabled`, and the first stream error becomes one diagnostic and ends that branch instead of reconnecting to the same offset 100 times (Pitfalls 1-2). Tests: news_item_is_rawpage_compatible, stream_error_omits_record_value. |
| T-02-02 | Information Disclosure | `describe_stream_error`, `decode_news` | medium | mitigate | Diagnostics carry topic, offset and at most 200 characters of the hint or serde error. `record_value` (the full page HTML) is never read or printed (Pitfall 3).
