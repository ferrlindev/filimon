<objective>
Move the repository to the toolchain and dependencies the Phase 3 host needs, without breaking SmartModule builds: a root `rust-toolchain.toml` (1.96.0), `rust-version = "1.95"`, the wasmtime 48 LTS, base64 and tokio-util dependencies, nested 1.85.0 pins for the three SmartModule crates, a README prerequisite update, and the `.fili-state/` ignore rule (RESEARCH Open Question 1, Pitfall 1, Pitfall 9).

Output: pin files, Cargo.toml and Cargo.lock changes, README text, gitignore line, and a successful `smdk build` as proof of the toolchain split.

- Root pin 1.96.0 with components clippy and rustfmt, because that toolchain is installed and already pinned by the plugin crates. Dockerfile untouched (it does not copy `rust-toolchain.toml` and its image follows stable).
- Nested pins: channel 1.85.0 and targets wasm32-unknown-unknown and wasm32-wasip1, the same targets the README lists today. The `smdk build` run in Task 2 is the check on RESEARCH A2 (rustup honours nested files was verified; `smdk build` itself was not).
