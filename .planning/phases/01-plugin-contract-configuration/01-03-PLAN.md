Purpose: Operators fix broken registries in one pass instead of one error per run. Phase 4's `fili plugins check` reuses these diagnostics.
Output: new `ConfigError` variants, validation in `load_registry_with_env`, and render-based tests.

The remaining research items, name rules (A11) and allowlist host validation (Security V5), are covered too.
