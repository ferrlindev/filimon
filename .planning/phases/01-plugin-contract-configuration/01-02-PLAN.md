Loading algorithm:
1. Read the registry once into a String. An IO error gives RegistryUnreadable; a parse error gives RegistryMalformed. Only these two short-circuit.
2. base_dir is the registry path's parent. `Path::new("filimon.toml").parent()` is `Some("")`, which joins correctly (Pitfall 9). Resolve every component and config path with `base_dir.join`; absolute paths stay absolute. Do not check that the component .wasm exists (A9; Phases 3 and 4 load components).
3. Visit sources in name order:
   - A disabled source is recorded with plugin None, and nothing else is read for it.
   - For an enabled source, read its plugin file once. An IO error gives PluginFileMissing, labelled at the registry `config` value. Parse it into PluginFile; a parse error gives PluginFileMalformed with the toml error span. Convert HostSection to HostConfig. Re-serialise settings with `toml::to_string`; an absent [settings] gives "". Key order and comments are not preserved (Pitfall 10).
4. Only if at least one enabled source declares [host.secrets], read `<base_dir>/.env` once with read_dotenv. A .env shared with docker-compose must not break plugin-free registries. On DotenvInvalid, push the error and resolve against an empty dotenv map.
5. Resolve each enabled source's secrets.
6. Push every problem into one `Vec<ConfigError>` and keep going (D-14). Return `Err(ConfigErrors)` when the Vec is non-empty, otherwise Ok. Never return a partial LoadedRegistry.

Build each file's parse result and its NamedSource from the same single read.
